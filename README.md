# 🎨 OpenFlow Studio

Visual Workflow Designer and Real-Time Execution Monitoring UI for [OpenFlow](https://github.com/Lab-OpenFlow/openflow).

## Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Canvas**: Visual workflow graph editor
- **Protocols**: REST & WebSocket streaming for real-time trace events

## Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation & Development
```bash
npm install
npm run dev
```

The app will run locally at `http://localhost:5173`.

### Production Build
```bash
npm run build
npm run preview
```
